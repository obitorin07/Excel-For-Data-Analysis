## ⚡ Google Sheets Automation (Python)

Automate your Google Sheets workflows using Python! The scripts in this repo can:

| Feature | Description |
|---------|-------------|
| 🔐 **Authentication** | Service Account based auth via Google Sheets API |
| 📥 **Auto-Merge** | Fetches all source sheets and merges into a single `master_data` sheet |
| 📊 **Pivot Report** | Auto-generates a `_master_report` with record counts by date |
| ⚙️ **Config Driven** | Sheet credentials managed via `config.py` |

### Quick Start
```bash
# Install dependencies
pip install gspread google-auth

# Run the automation
python app.py
```
